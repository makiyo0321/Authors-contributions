# Contributing

Describe the problem, expected behavior, Python version, OS, and reproduction steps.
Use fictional names and sanitized project files. Never include private author data.

Install requirements.txt, make a focused change, and run:
    python -m unittest discover -s tests -v

For UI changes, check English and Chinese, long names, empty projects, and window resizing.
Verify that switching language and reordering authors preserves assignments.
Keep user-facing text bilingual. Explain validation performed in your pull request.
